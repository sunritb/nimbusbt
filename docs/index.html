NimbusBT

A modern, secure, open-source BitTorrent client

Built on Node.js + WebTorrent. Runs on macOS, Linux, and Windows with a responsive web UI, a command-line interface, and a secure REST/WebSocket API.

View source on GitHub Download release

Features

  • Add via .torrent, magnet, or path
  • Download & seed with file priority
  • DHT, PEX, LSD, uTP
  • IP blocklist (PeerGuardian/PGL)
  • Time-of-day bandwidth scheduling
  • SOCKS4/5 proxy for peer traffic
  • Malware scan + VirusTotal hooks
  • Token-protected Web UI (PWA)

Quick start

npm install
npm start — open http://127.0.0.1:5050/

Requires Node.js ≥ 22.5.0.
